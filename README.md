# Pritam Bhunia — Animated Portfolio

A modern, responsive developer portfolio built with pure **HTML, CSS and JavaScript**.

## ✨ Features

- Animated hero section with interactive particles
- Scroll reveal animations
- Responsive mobile navigation
- Cursor glow effect
- Animated project cards
- Modern dark UI
- Fully responsive layout
- No framework required
